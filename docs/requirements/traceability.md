# Assessment requirement traceability

Status terms and fresh account-free results are recorded in [evidence status](../evidence/status.md). Static success never promotes a live counterpart. `implementation-deferred` means the current baseline has a known gap and cannot satisfy the requirement merely by being deployed; `not-applicable` is used only for choices the supplied assessment explicitly makes optional or that do not apply to the selected stateless/Autopilot design.
